# Gerenciador de Turma - Educação Física (TypeScript)

## Este projeto demonstra a implementação de um CRUD (Create, Read, Update, Delete) utilizando TypeScript puro e manipulando o DOM de forma tipada e segura.

## Funcionalidades Técnicas:

- Type Casting: Mapeamento rigoroso de elementos do DOM (HTMLInputElement, HTMLFormElement).
- Lógica de IMC: Cálculo automatizado via método da classe Aluno.
- Estilização Condicional: Manipulação de classes do Bootstrap baseada em regras de negócio.
- Asynchronous JS: Consumo de API externa utilizando async/await.
- Event Handling: Gestão de eventos de formulário e escopo global para funções de edição/deleção.
